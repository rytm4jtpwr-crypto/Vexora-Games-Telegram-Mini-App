Переделай визуал и анимацию Rocket Game под референс из предоставленного screen recording.

==================================================
1. РАКЕТА
==================================================

В RocketGame.tsx найди существующий:

<img
  className="rocket-model-image"
  src="/assets/neon-rocket-model.png"
  alt="Неоновая ракета Vexora"
/>

Оставь этот asset.

Ракета должна:
- плавно лететь по траектории;
- смотреть по направлению движения;
- слегка покачиваться;
- иметь постоянное свечение;
- иметь отдельное анимированное пламя двигателя;
- не прыгать между кадрами;
- не телепортироваться при переходе betting -> flying;
- не исчезать во время полёта.

Используй requestAnimationFrame для плавного визуального движения, но НЕ создавай отдельный игровой таймер, который будет расходиться с multiplier.

Multiplier остаётся источником истины.

==================================================
2. ОТДЕЛЬНОЕ ПЛАМЯ
==================================================

Не встраивай пламя внутрь изображения ракеты.

Создай отдельный элемент:

<div className="rocket-flame">
  <div className="rocket-flame-core" />
  <div className="rocket-flame-glow" />
  <div className="rocket-flame-particles" />
</div>

Он должен быть расположен непосредственно под соплом ракеты.

Пламя:
- magenta/pink в центре;
- blue/violet по краям;
- яркое белое ядро;
- слегка меняет длину;
- слегка меняет прозрачность;
- имеет glow;
- движется независимо от ракеты;
- не влияет на положение ракеты.

Сделай CSS-анимацию примерно такого типа:

rocketFlamePulse:
0%   scaleY(.72) scaleX(.88)
50%  scaleY(1.12) scaleX(1.04)
100% scaleY(.78) scaleX(.92)

Анимация должна быть быстрой и непрерывной.

Также добавь маленькие частицы вокруг пламени.

НЕ используй GIF.
НЕ используй canvas.
НЕ используй внешние библиотеки.

==================================================
3. ПОЗИЦИЯ РАКЕТЫ
==================================================

Сохрани существующую функцию:

getTrajectoryPoint(progress)

Но сделай движение визуально более плавным.

Используй:

const flightProgress =
  phase === 'betting'
    ? 0
    : phase === 'crashed'
      ? Math.min(
          1,
          Math.log(Math.max(multiplier, 1)) / Math.log(100)
        )
      : Math.min(
          1,
          Math.pow(
            Math.log(Math.max(multiplier, 1)) / Math.log(100),
            0.72
          )
        );

Это нужно для того, чтобы ракета в начале двигалась заметно, а затем быстро уходила вверх.

Траектория должна идти:
нижняя левая часть -> центр -> верхняя правая часть.

Ракета должна быть внутри игрового поля.

Не допускай выхода ракеты за правую/верхнюю границу.

==================================================
4. УГОЛ РАКЕТЫ
==================================================

Ракета должна автоматически поворачиваться по касательной к траектории.

Не используй постоянный rotation.

Если текущая траектория:

P1 = предыдущая точка
P2 = текущая точка

то:

angle = atan2(P2.y - P1.y, P2.x - P1.x) * 180 / Math.PI

Учти, что изображение ракеты визуально направлено вверх, поэтому добавь необходимую поправку rotation.

Должно выглядеть так, будто ракета реально летит вдоль линии.

Добавь небольшой wobble:

Math.sin(time / 90) * 1.5

но wobble должен быть очень маленьким.

==================================================
5. ПЛАМЯ ДОЛЖНО СЛЕДОВАТЬ ЗА РАКЕТОЙ
==================================================

Пламя является child/overlay относительно rocket vehicle.

Структура:

<div className="rocket-vehicle">
  <div className="rocket-flame">
    ...
  </div>

  <img
    className="rocket-model-image"
    src="/assets/neon-rocket-model.png"
    alt="Неоновая ракета Vexora"
  />
</div>

Пламя должно находиться ЗА ракетой по z-index.

Пример:

rocket-vehicle:
  position: absolute;
  transform-origin: center center;

rocket-flame:
  position: absolute;
  left: 50%;
  top: 92%;
  transform: translateX(-50%);
  z-index: 0;

rocket-model-image:
  position: relative;
  z-index: 2;

Не допускай, чтобы пламя перекрывало корпус.

==================================================
6. BETTING
==================================================

Во время betting:

- ракета находится в нижней части сцены;
- ракета видима;
- двигатель слегка светится;
- пламя короткое;
- ракета слегка покачивается;
- countdown показывает 5 -> 4 -> 3 -> 2 -> 1;
- после countdown начинается flying.

НЕ скрывай ракету через:

opacity: 0;

Удали/переопредели старое правило:

.rocket-stage.phase-betting .rocket-vehicle {
  opacity: 0;
}

Итоговая opacity во время betting должна быть 1.

==================================================
7. FLYING
==================================================

Во время flying:

- multiplier увеличивается;
- ракета движется синхронно с multiplier;
- траектория светится;
- пламя становится длиннее;
- вокруг ракеты появляются небольшие particles;
- ракета слегка покачивается;
- фон остаётся тёмным;
- никаких резких скачков.

Сделай эффект:

.rocket-trajectory {
  filter:
    drop-shadow(0 0 5px rgba(...))
    drop-shadow(0 0 12px rgba(...));
}

Но не перегружай экран glow-эффектами.

==================================================
8. CRASH
==================================================

При phase === "crashed":

- ракета останавливается на последней позиции;
- пламя быстро уменьшается;
- появляется взрыв;
- ракета может слегка исчезнуть после взрыва;
- multiplier фиксируется;
- показывается результат.

Используй существующие:

.rocket-explosion
.explosion-burst
.explosion-orbit

Не создавай старые неиспользуемые explosion-классы заново.

Взрыв должен быть коротким:
примерно 500-700ms.
